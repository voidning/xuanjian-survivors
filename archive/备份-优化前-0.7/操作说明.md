# 几笔长生 · 操作说明（0.7.0）

双击「启动游戏.command」开始。关闭打开的终端窗口即可停止服务。游戏依赖已放在本地，无需账号或安装依赖。

## 开始一局

选青尺剑、青乌弓或杜若枪，再三选一学习起手神通。移动避敌、自动攻击、靠近拾取经验；升级时战斗暂停，选择成长后继续。首领被击败后战斗继续，只有死亡或主动结束才结算。

## 操作

| 操作 | 按键 |
|---|---|
| 移动 | WASD／方向键，或点击地面；键盘移动会取消点击目标 |
| 选择成长 | 点击卡片或按 1／2／3；选择箓气时可按 1—4 |
| 武器技 | 默认按战况自动施放；空格主动使用，R 切换自动／手动 |
| 血漠挪移 | E；需学会赤断镞并位于自己的血漠内，消耗 8 法力 |
| 箓气主动能力 | Q；仅竭命功成具有主动能力 |
| 暂停／继续 | P／Esc；暂停菜单可结束本局并结算 |
| 神通谱 | Tab；查看期间暂停战斗 |
| 开关音效 | M |

普通攻击不耗法力。武器技和自动神通需要满足目标、法力与冷却条件；武器自动施放还会预留 12 法力。寿元不会自动消耗。

## 果位与成长

- 明阳：谒天门、君蹈危、帝观元、赤断镞、天下明。侧重甲兵协战与近身控场。
- 渌水：洞泉声、如重浊、丑癸藏、清夕雨、洗劫露。侧重惑敌、藏匿与持续磨阵。

另有六道独立神通：溪上翁诱敌聚群、位从险收束陷敌、镂金石强化普攻、天金胄凝甲承伤、靖平敕近身荡雷、雉离行吐焰炎行。可自由搭配，当前不参与果位激活。

每组五道各一级激活果位。神通最高三级，强化不重复计数。两组可以混选、同时激活，没有神通槽位限制。选择界面显示已学等级、果位缺项和选后进度。

参悟后回复 20 法力；修行等级每提升一级，法力回复增加 0.3／秒，额外回复最多 5／秒。候选随机，不保证补齐同参。击败精英或首领获得重抽次数；首次击败可触发一次箓气选择。

每局一件武器、一种箓气，选定后不更换。重开清空本局成长；同种子重开保留初始随机种子和武器，操作不同时后续局面仍可能不同。

## 战场提示

留意冲锋路径、远射蓄势和地面危险预警。自己的血漠可供挪移，带叉号的地面区域来自敌人。喘息阶段停止补充普通敌群，适合清场拾取；现存敌人和精英、首领仍会行动。

双刃从侧面绕近再扑斩；鼓手会召来有限数量的随从，优先击败可切断增援；符师横向封路，中央留有缺口。精英还会连冲、扇射、追加震地或扩大阵势，留意第二次预警。

神通谱新增「敌情」，可暂停查看每类敌人的普通行为与精英招式。详细设定在「神通谱 → 设定与效果说明」中查看。

## 神通评级

S 级核心强能、A 级主力搭配、B 级实用补足。评级是本作设计，与本局 1～3 级修习等级分开显示。选择卡、已学神通和神通谱均可查看评级；果位仍需五道同参各一级。详细数值见独立的「原作设定与游戏表现对照」页面。

## 看懂战场

屏幕时间旁显示追击聚群、侧翼夹击、阵线压迫或喘息拾取。喘息时优先收取经验，仍要注意残敌、精英和首领。淡青泉点对应洞泉声剩余助击；金色冠形标记表示甲兵正受天下明强化。

## 神通实时反馈

赤断镞展开后，进入血漠查看右侧的记伤量和 E 挪移状态；离域或收术会返还所记伤势，敌人也适用返伤。底部神通栏显示每道能力的实际持续状态或冷却；右侧最多显示三条施放和结算提示。


## 这版新增

- 溪上翁、位从险：从后续成长中随机获得，可与已有神通自由搭配。幻饵诱敌，险地优先落在幻饵附近；两道本身不直接造成伤害，配合范围攻击清群。敌人受击后更快摆脱诱引，精英与首领更难控制。
- 光幡使：看紫色扇射线，从光芒间隙通过。链镰牵手：侧移离开橙色窄道，避免被拉近。逐风猎犬：看到俯身与直线预警后横移，精英落点还有第二次撕咬预警。
- 普通敌人生命、后期速度与伤害提高，精英间隔随时间缩短；喘息阶段仍可收取经验。
- 神通动画增加钓线、水纹、险地山脊、门框升起与分叉雷霆。自己的技能范围有名称和时间弧，敌方攻击仍使用橙色或紫色预警。

并火、离火本轮因资料访问受阻暂未加入，缺项已列在独立设定页。此版未进行试玩或平衡测试，由玩家实际体验后反馈。
