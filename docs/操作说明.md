# 操作说明 · 0.26.0 仙基入道

启动游戏后选择青尺剑、青乌弓、杜若枪或六雷玄罚令，再从明阳、渌水两道统共十道仙基中选择一道。重明洞玄屏暂无伤害普攻，本版暂不开放开局。开局选择锁定道统，此后只能修本系五法，其他旧技能保留图鉴、待开放。

## 从仙基到神通

- 明阳：谒天门、君蹈危、帝观元、赤断镞、天下明。
- 渌水：洞泉声、如重浊、丑癸藏、清夕雨、洗劫露。

一、二重是仙基蕴养，不启用对应神通的战斗效果，先依靠器物普攻与器物技杀敌、拾取经验。谒天门例外：一、二重可短暂落门镇压，14 法力、9 秒冷却，范围 75/95，普通敌人停顿 0.6/0.8 秒；不召兵。

将二重升为三重才成就一道神通。第 1—5 道神通的突破等级门槛依次为 7、11、15、20、24；未达门槛时继续蕴养其他仙基或选择修行强化。开局仙基在尚未成就第一道神通时会获得候选保障，出现候选仍须自行选择。

零道神通为筑基，一道为紫府，三道为紫府中期，四道为大真人，五道为五法圆满；两道时仍为紫府。本局重数、等级门槛和境界进程均为游戏规则，不是原著逐字规则。当前没有果位玩法，也不能跨系混修。

每次参悟回复 20 法力。修行等级提高后，基础回法每级增加 0.3/秒，额外最多 5/秒。二级起可出现局内修行强化；它们不计入成就神通数。重开清空本局成长。

## 操作

| 操作 | 按键或入口 |
| --- | --- |
| 移动 | WASD／方向键，或点击地面；键盘移动取消点击目标 |
| 通用瞬移 | 空格或按钮，距离 140、冷却 6 秒；不耗法力、不无敌 |
| 器物技 | G 或按钮；R 切换自动／手动，默认自动 |
| 选卡 | 点击选择；普通三选一可按 1／2／3 |
| 暂停 | P／Esc，可设主修、指定手动神通和调整设置 |
| 图鉴 | Tab，查阅期间暂停 |
| 音效 | M |

普通攻击免费，器物技和普通神通按法力、目标与冷却条件施放。只有三重神通可设为主修或 F 手动；被动不能手动施放，同一道不能兼任主修与手动。

赤断镞三重生成血漠后，E 可在自己的血漠内挪移，耗 8 法力、冷却 2.8 秒。血漠记录域内实际战伤，离域或收术返还，敌人也会返还；致死伤不能救命。仙基阶段没有血漠或 E 挪移。

天下明三重可在暂停页自行指定 F，启用蓄能六合敕令：首次能量 100，有效近敌战斗每秒 +2.5，击杀另有加成、每轮最多 +12。满能按 F 或按钮发出三次敕令，消耗全部能量，不耗法力。切换不会再次补满，切回自动恢复普通单次施放；不会自动替换其他手动神通。天下明只强化当时在场的甲兵。

首次符合受箓条件时可选择一种箓气，每局选定不更换。竭命功成的 Q 消耗一格不可治疗补回的寿元，回复法力并短时增伤。谷风引火因其关联技能尚未开放，暂不进入受箓候选。

## 战斗与机缘

靠近拾取经验，优先避开冲锋、飞弹和敌方地面危险。三重清夕雨定点落下，不跟随玩家；三重丑癸藏只改变追踪位置，已发出的攻击仍危险；三重洗劫露只清地面危险并提供短时地面护行，不免疫飞弹或接触。

默认十二分钟破阵挑战：撑到十二分钟并击败终阵才胜利，普通首领被击败后继续。胜利后可继续无尽，也可开局选择无尽模式。

同一时间只出现一处可选机缘。行囊需圈内连续停留 2 秒；据守需累计守住 10 秒；携物敌修需追击击败；试阵需击败三名旗记守卫。奖励和剩余时间看界面，暂停与选卡冻结计时。忽略或失败会错过奖励；放弃不额外扣资源，已惊动敌人仍留在场内。

## 记录与设置

结算记录道统、境界、已成就神通数、境界历程及本局搭配。历史记录保留，旧版果位信息只代表旧局，不会转成当前玩法。施放次数不代表伤害贡献，旧记录缺失信息不补造。

记录保存在当前浏览器本地，可导出备份或合并导入；不保存战斗中途进度。继续使用启动脚本的固定地址与同一浏览器，清理浏览器数据可能清除记录。音量和减少装饰动效设置会保留，危险预警始终显示。
