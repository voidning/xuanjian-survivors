# 0.30.0 离火与兑金试玩版

新增两个道统，共四道统、二十道开放仙基。现有明阳、渌水成长与难度未调整。开局页每个道统五张卡，数字1—5选择当前道统内仙基。同步选卡、暂停、神通谱、修行记录与内嵌说明。各道统仍沿用7/11/15/20/24级突破门槛，境界全屏提示及减少动态效果设置保留。

## 玩家可感知的变化

- 离火：大离书近敌心火、九重擭短网转多层离网、顺平征得胜加速转持续征域、位从罗命中凝法并在三重储法、折焚尽余焰转范围回响。
- 兑金：不穷锋短锋转长锋、君兑隅锋隙转秋域、杀收宫二/四锋刃转十六锋刃、金窍心感知与普攻调度、位从孚脱离蓄势威胁后应势加速，三重可强化两次普攻。
- 低重主动作用每次5法力，4.5—6秒冷却；命法被动有触发条件与独立冷却。资料缺口不以原著事实表述。
- 法域仅使用轮廓，保留敌弹和地面预警；新局部效果减少动态模式下取消扩张/转动。

## 原作依据与改编边界

原作季越人《玄鉴仙族》。离火五法组合参考《顺平》《离火道途》，兑金采用剑门相关五法，参考《折毁》，不是所有兑金修士的通用配方，不附赠人物剑意。

大离书《昶离》：心火与行走；九重擭《兄妹》：离网步步为营（转载字形有差异）；顺平征《顺平》《窞境》：控摄诸地、破阵响应；折焚尽《并阳》：善全与统筹；位从罗《无上秘》《求藏》：正统求余；金窍心《奴孜怜愍》：仙基层敏锐感知；君兑隅、杀收宫《梨花剑》：秋色锋隙、十六刃对准一处；不穷锋《梨花剑》《不穷》：攻伐长锋，人物剑意另论；位从孚组合已核，具体斗法资料不足。

一二三重与具体数值均为游戏规则。位从罗命中回法、折焚尽积层余焰、位从孚脱势加速是经用户同意的游戏设计，不宣称原著有这些战斗动作。完整阶段表见同目录《原作设定与游戏表现对照.md》。不改动存档结构或清空旧记录。
