# 0.32.0 · 轻装入山

本版针对手机、平板触屏和窄视口的战场遮挡、重复 DOM 更新与 Canvas 渲染开销。沿用 Phaser / Canvas、原有纸墨配色与自动战斗玩法。

## 玩家可感知的变化

- 战斗中保留气血、法力、时间、经验、首领血条与需要手动操作的技能。五法详细数值、资源、施法反馈与设置集中到「详情 · 暂停」，打开后暂停战斗。
- 自动器物模式下不重复展示手动器物按钮；暂停中可切换为手动。瞬移始终保留，其他已解锁的手动能力继续可用。按钮较多时可横向滑动。
- 手机移除重复的小地图；机缘保留名称、倒计时、方向与距离，详细任务和奖励在暂停中查看。系统通知移到底部，最多显示两行。
- 支持屏幕旋转、安全区域与动态视口高度。战场菜单打开时隐藏背后的 HUD，避免叠层干扰。
- 修复按钮在每次 HUD 刷新时整组重建的问题；触屏按下到松开期间，冷却更新不再替换按钮。
- 减少场外绘制、重复特效统计及静止菜单后的战场重绘。维持 60 帧目标，不更改战斗时间、伤害或敌人数量。

## 原著与改编边界

没有新增或更改原作设定、神通能力、阶段规则与战斗数值。HUD 收纳、显示裁剪和缓存属于界面、渲染实现。存档键与旧记录兼容规则保持原样。

## 实际验证

- Chromium 手机/平板模拟：320×568、390×844、844×390、768×1024；桌面：1024×768、1440×900。正常选择器物、选择仙基、进入战斗、暂停与恢复，无页面脚本错误或横向页面溢出。
- 模拟触摸按住 350 毫秒跨越多个 HUD 刷新周期，按钮 DOM 保持同一实例，松开后瞬移触发；桌面鼠标同样验证。
- 390×844 下，底部 HUD 从约 203px 降为 72px；右上 HUD 从 132px 降为 44px。此为布局测量，不代表帧率。
- 构造场景验证首领血条、五个手动操作入口、燃寿按钮、暂停详情与横竖屏切换；这些不是自然成长通关证据。
- `node tests/cultivation.cjs` 8/8；`node tests/dash.cjs` 5/5；`node tests/dasheng.cjs` 6/6；`node tests/medicine.cjs` 8/8。升级版本后同步更新 cultivation 的版本断言。

浏览器回归脚本：`tests/mobile-browser.cjs`、`tests/mobile-scenarios.cjs`。需要 Playwright 与 Chromium；先运行本地 HTTP 服务，再执行脚本。可用 `XJ_URL` 指定入口（以 `/` 结尾），默认 `http://127.0.0.1:18743/`。脚本截图写入 `work/mobile/`。

## 渲染压力对照与既有测试

桌面无头 Chromium，390×844、DPR 1，构造 160 敌人、240 弹道、110 掉落、120 特效（绝大多数位于屏外），预热 12 次后直接绘制 160 次。本次复验中位数 3.30ms → 0.30ms，p95 12.20ms → 0.60ms，均值 5.59ms → 2.00ms，两版无脚本异常。该测试突出屏外裁剪收益，不包含完整战斗计算，也不能推算实体手机 FPS。地图缓存仍约 28.9MB，本版未宣称减少其内存占用。

`tests/mobile-performance.cjs` 可用 `XJ_BASELINE_URL` 指向未修改的源码服务、`XJ_URL` 指向当前源码服务复验（均以 `/` 结尾并支持 `?test`）。发行版已移除场景注入接口，不能直接用于此构造测试。

`tests/playability-smoke.cjs` 的 10 组 150 秒输入模拟通过（程序模拟，不是浏览器自然通关）。旧 `tests/core-loop.cjs` 在原版和本版均为 3/9：六个主修调度/旧文案相关失败名称完全一致，属于已有测试失败，本次未修改这些规则。

离线单文件已在 Chromium 直接打开验证：进入战斗、暂停/恢复通过，无外部网络请求，不包含场景注入接口。

## 待验证

尚未在实体 iPhone / Android 或 Safari 上测量持续战斗帧率、功耗与发热，未进行真人十二分钟通关。模拟器与桌面 Chromium 的性能结果不能等同于实体手机收益。刘海屏安全区域使用系统环境变量，仍需实体设备确认。
