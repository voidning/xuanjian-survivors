# 邺桧斗法：原著依据与游戏实现

版本：0.34.0 · 白山紫水。作品：季越人《玄鉴仙族》。本轮读取原文章节正文，不以百科或搜索摘要作能力依据。转载章号存在差异，以章名定位。只记录小范围释义，不收录章节全文。

## 已核对的原著事实

- 《都仙事》（部分目录第715章）：李家、玄岳与白邺都仙道存在利益冲突；邺桧修都卫，已成三道神通。本文不把对其旧事的怀疑写成确凿罪行。
- 《一符一箓》（第757章）：邺桧与李曦明交手时，白气山峰压制天门，紫水中人首鱼抵住金甲兵马。两法均有镇压、阻拦表现；雷霆与真火来自另外的符箓灵器，不属于这两道神通。
- 《飞举山落》（第906章）：白色飞山有镇压表现；东羽山与生翼悬山相关，南惆水显出人首紫鱼并化作紫水。人物着深蓝玄纹袍、长发、抱剑；章末列为紫府中期。

选用与李家交锋时期的敌对人物形象，不概括为终身敌人，也不复刻原著事件。玩家无需扮演李曦明。山场相逢、前置编队、击退结果均是本作关卡编排；不宣称邺桧在原著于山场被杀。

## 本版实现

六分钟起的常规首领位，玩家已成至少一道神通时，本局第一次符合条件的首领替换为邺桧。原首领仍在场则沿原三分钟调度顺延；标准模式终阵不使用人物替换。准入是游戏节奏门槛，不是宣称一神通必能胜过原著紫府中期。

- 气血2100，半血一次转段；不随玩家输出自动抬高血量。
- 东羽山：锁定玩家当时位置，1.45秒橙圈预警后落山，半径72，危险持续1.25秒。沿用地面危险伤害、受创迟滞及现有防御结算。定点、范围、伤害频率皆为游戏规则，不新增原著落山招式名称。
- 南惆水：锁定方向，1.25秒后发出三道紫水人首鱼形法术飞弹；第二阶段五道。速度205、寿命2.7秒、单枚基础伤害14，后续受现有伤害规则影响。扇形弹道是对紫水鱼潮的游戏抽象，不等同于原著独立妖兽。
- 两招交替；第一阶段施法后收势1.8秒，另有1.2秒换位；第二阶段收势1.25秒，另有0.8秒换位。半血取消当前蓄势、给2秒换段空档，可照常受伤。没有阶段无敌或锁血。
- 如重浊等现有打断与控制保留；天下明、彩彻云衢按现有消弹机制反制鱼潮；地面抵御按既有规则处理落山。走位本身可避两招，不要求抽到某道神通。这里不宣称原著具有统一的弹道抵消规则。
- 不实现西天塬、太虚通行与封锁、雷火符箓、三顼舍素玄光，不把人物所有手段压缩为一套全能技能。

## 编队、压力与记录

约5分与5分25秒的可生成敌群时段，以“远射夹阵”和“护持逼近”各替换一组普通敌群。前者结合远射、封路，后者结合护持、冲锋；受标准模式威胁预算及对象池上限约束。它们属于山场游戏编队，不声称原著邺桧统领这些兵种。

人物斗法期间暂停新增精英；普通敌群改为每5秒检查一次，非蓄势且在场敌人少于28时最多添两名围攻者。既有残敌、机缘守卫仍在，不能称为纯单挑。

击退沿用普通首领奖励：重抽2次、气血回复24（不超过上限）、经验掉落95；没有第二份额外成长。只记遇见、转段、击退时间。标准模式11分15秒未击退时收法退场，清除其遗留法区与飞弹，不领奖、不记击退；原终阵独立开始。修行录无永久战力。
