# 项目结构

- 根目录：游戏入口、启动脚本与项目说明。
- scripts/：游戏脚本和离线打包工具。
- styles/、assets/、vendor/：样式、美术资源、本地引擎。
- tests/：测试代码和浏览器测试页；results/存放历史测试输出。
- docs/：设定、操作与考据；versions/存放版本说明，references/存放参考资料，maintenance/存放维护和恢复说明。
- 发行版/：当前版与上一版离线单文件。
- work/：运行测试时自动生成的临时目录，已加入Git忽略规则。

2026-09-11只整理文件位置；游戏版本、脚本加载顺序、入口地址和存档规则均未改变。
离线打包命令保持 python3 scripts/build-release.py，版本说明从 docs/versions/读取。
