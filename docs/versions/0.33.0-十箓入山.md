# 0.33.0 · 十箓入山

本版在 0.32.0 移动端优化基础上新增五道箓气，共十道开放定义。每局只能受一道，不能叠加或换箓。谷风引火仍保留历史记录，本版不开放。

## 玩家可见变化

- 力贯千钧：剑、弓、枪、戟普通攻击的实体基础伤害提高 30%，亦强化穿云箭和长戟实体重扫。附加法术不随之增幅。不使用实体兵器时不进入受箓候选。
- 避死延生：脚边单个方向标提示迫近飞弹、冲锋或地面险区；每 0.15 秒评估，不自动闪避、不复活、不保命兜底。
- 彩彻云衢：主动术法成功施放后开启 0.8 秒解术窗口，化去身边 90 范围内最多 2 枚飞弹，每 6 秒至多触发一次。不抹除首领法区。
- 明霜松岭：受创时保持身形稳定；地面法区所致受创迟滞从 1.2 秒缩短到 0.45 秒。伤害、钩索拖拽和既有无敌时长保持原规则。
- 贪罟玄离：离火路线南明心火三重后可受。心火伤害提高 30%；心火击杀每秒至多额外获得 1 点参悟经验。不吸血、不增加寿数、无即死。
- 长空危雀：由只有自身受伤触发改为自身受伤或对附近敌人造成有效伤害触发。悍勇持续 5 秒，触发间隔 8 秒，避免持续刷新迫使玩家吃伤。
- 保留重海长鲸的厚法力、竭命功成手动燃寿、行气吞灵驾雾游走和明彰日月现有破敌收益。旧存档 ID 不变。
- 受箓改为短卡、分类、每页最多三道，先查看再确认。可暂缓受箓，下一次击败精英或首领再选；满足贪罟条件后无需换箓。
- 图鉴与暂停页补齐规则和原作边界；新增统计只在菜单展示，战斗中不常驻大型数值面板。
- 小范围水线、松针、短彩弧、收束火纹与危险方向标替代额外的大范围泛光。沿用对象池与 0.32.0 移动端 HUD、画面裁剪、静态菜单停止重绘。

## 原著依据与改编边界

作者均为季越人，作品均为《玄鉴仙族》。章节编号在不同目录中存在偏移，以章名与人物情节定位。

| 箓气 | 本次核对章节 | 核实内容与边界 |
| --- | --- | --- |
| 力贯千钧 | 《求箓》《旦夕之祸》 | 气血体魄增强、肉身碎石、驾驭强弓。30% 仅为游戏数值。 |
| 避死延生 | 《避死延生》《避无可避》 | 可感祸患与死兆，但李项平仍会遭遇避无可避。仅实现感知支脉，不声称已覆盖全部化灾之能。 |
| 彩彻云衢 | 《余地》《彩彻云衢》 | 保全心力、振奋心神、容易化解他人术法，久修增益法术。解术窗口为战斗抽象，不把多年修炼压成瞬时法力。 |
| 明霜松岭 | 《得手》《侠义（上）》 | 《得手》明确运转箓气排除疼痛和情绪干扰；并火侵袭仍会盖过效用。缩短受创迟滞是游戏抽象，不推导抗火、冻结或松上雪能力。 |
| 贪罟玄离 | 《贪罟玄离（2）》 | 性命感应、夺取他灵、离火灵物养性命，别人性命仅助修；直接提升大离书南明心火威力。不授予未学的玄擭法，不凭空生成灵物。 |
| 长空危雀、行气吞灵 | 《杀妖受箓》 | 前者见血悍勇、腾挪驾风；后者操云驱雾并有服气修行作用。只落实战斗中有依据的窄范围表现。 |
| 重海长鲸、竭命功成 | 《收获镜面》 | 厚法力与燃寿换法力、战力。保留已实现数值。 |

《渊修祭祀》明确每人仅能得一道箓气；《避死延生》说明依资质敕封的玄珠符种前提。游戏单角色受箓资格为既有设定前提，构筑筛选与数值节奏为游戏规则。明彰日月字形沿用旧版，本轮未独立核到名称原文，不宣称已经解决与读者提供“明璋日月”的字形差异。

## 验证

- 箓气构造契约 12/12：资格与一次性、暂缓/再次受箓、实体伤害范围、悍勇触发、解术上限、预警方向、守心迟滞、心火真实法区接入、燃寿与旧档兼容。
- 回归：修行 8/8、闪避 5/5、长戟 6/6、丹药 8/8。
- 十场 150 秒输入驱动模拟，无注入生命、修为或技能；全部生存至结束，九场取得目标箓气，贪罟玄离种子 42 在该时间内尚未取得。不是玩家操作或完整十二分钟通关。
- 六种浏览器视口：320×568、390×844、844×390、768×1024、1024×768、1440×900。触控按钮保持、暂停、手动器物控制、HUD 不重叠通过。
- 四种视口受箓选中/独立确认通过，均无横向页面溢出或脚本异常；键盘当前页映射、独立确认、图鉴分页、暂缓与减少动态效果均通过。
- 同机 390×844 视口、160 敌人/240 飞弹/110 掉落/120 特效的构造绘制对照：0.32.0 与本版中位数均约 0.3ms，P95 约 0.7/0.8ms。该测试只反映此机器的脚本绘制提交耗时，不是手机帧率或 GPU 端到端测量，不能宣称真机不卡。
- 旧 core-loop 套件 3/9；六项失败与未修改的原项目逐项一致，为既有失效用例，本轮未修复。
- 尚未进行真实手机、长时热降频、完整十二分钟平衡或全部种子通关验证。

- 最终单文件发行版在断网浏览器中正常入山、暂停和打开十箓图鉴；已移除测试注入入口。发行目录仅含 index.html。
