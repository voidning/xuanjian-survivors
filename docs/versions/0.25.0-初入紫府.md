# 0.25.0 · 初入紫府（试玩原型）

2026-09-09。独立工作副本，桌面原版未覆盖。

## 玩家可见变化

- 初入紫府开局；最多三道核心神通，各修至三重。十九道仍在内容库中，当前允许跨道统混选。三槽、混选与局内重数都是游戏规则，不是原著修行上限或完整传承体系。
- 删除果位配方、五道收集门槛与新局果位奖励。已有神通尚可升重时，成长候选保障一次精修机会；其余候选随机，满槽后不再发第四道神通，满重后继续强化和补给。
- 天下明三重可由玩家在暂停中指定 F，使用蓄能六合敕令。不会抢占原来的手动设置。手动时停止普通自动天下明；切换不重新补满蓄能。全部自动仍可游玩。
- 天下明与谒天门原有甲兵响应保留。谒天门三重每次六名，总上限八名。
- 清夕雨三重强化定点雨势：范围212.5、持续7.425秒、每跳22.5；持续受雨两秒后破护，离雨延续三秒。取消跟随玩家。
- 洞泉声三重六次助击。持屏候选排除洞泉声与镂金石；满槽且没有雉离行时不提供谷风引火。
- 旧存档的历史果位和超三道搭配记录兼容保留，不重置数据；新局不再引导达成果位。
- 离线发行仅一个 index.html，内含运行库、图片与设定说明。

## 原著依据与改编边界

作品《玄鉴仙族》，作者季越人。

- 《神通》（检索章号686，部分来源683）：仙基孕育神通与紫府突破。本版只采用初入紫府定位，没有实现筑基突破或为十九道能力编造前身。
- 《六合》（检索章号1050）：六合光禁闭、消解恶难及与甲兵响应。保留能力关系；F、三次节拍、能量、三重门槛、召兵数量均为游戏设计。
- 《贪罟玄离（2）》（1141）：清夕雨持续压阵。将其映射为定点磨护；范围、秒数、伤害为游戏设计。
- 《观礼》：五道神通与突破金丹不同。本版不模拟求金、果位或双果位叠加。

未扩充命身术类别、道统兼修资格或新核心能力。未核实内容继续保留原资料的边界说明。
