# 0.35.0 · 金销藏器

保留邺桧，新增更早登场的阶段性对手郁慕仙。

## 玩家可感知的变化

- 筑基修为达到5级且尚未成就神通时，可提前遇见郁慕仙，替代原三分钟首领位。战中正常升级和突破。错过条件则按原首领节奏进行。
- 六面法盾与八枚菱形法器，先破护身、再趁收势追击；金色射线预告交叉攻击，半血以金莲护身。
- 邺桧的白山紫水斗法、六分钟准入、两组中段编队和终阵规则保留。
- 两人的人物绘制、护身效果、预警、首领提示、指南与修行录分别呈现。旧邺桧记录和旧存档继续可读、可导入。

## 原著与改编

人物阶段、六盾、八枚法器、金莲护身取自季越人《玄鉴仙族》第467章《交战（上）》；原著结局定位第469章《剑斩》。金销洞是仙基，不是紫府神通。山中遭遇、等级门槛、护盾耐久、锁定射线与半血转段为游戏编排；未实现全部灵器、术法与符箓，不改变原著人物结局。详见郁慕仙斗法依据与实现。
