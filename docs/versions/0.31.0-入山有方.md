# 0.31.0 · 入山有方

本版完成首轮诊断与上手体验优化，仍是试玩版，不宣称四道统平衡已通过验收。

## 玩家可感知的改动

- 四个道统增加打法说明与起手参考；仙基卡先讲当前作用，再讲未来神通，精确数值和原作边界留在展开说明中。离火提供顺平征远处征域、大离书近身游走两种起手方向。
- 升级后的提示缩短，补齐新九法的简短成长反馈；升级界面的主修说明继续展示道统走位提示。没有新增神通或改变同道五法限制。
- 养息每阶回血由 0.15/秒调整为 0.25/秒，三阶由 0.45/秒到 0.75/秒。需要占用选卡机会，不附赠、不复活、不回寿元，暂停时不回复。
- 大离书三重只在实际心火半径 115 内有敌人时启动，自动和手动遵循同一条件。修正此前距离 160 的敌人能触发施法、却在半径 115 外不受伤的问题。伤害、持续时间、冷却和心火范围保持原值。
- 增大经验珠并提高墨绿对比；角色头顶增加静态定位标记，减少动态效果时仍可辨识。只改绘制，不改碰撞和拾取范围。
- 版本、开局按键说明与发行包同步更新，保存格式和历史记录保持兼容。

## 定位结果

基线源码提交：`febb7ea6b79b761771f153879591eddc97f19117`。

1. **测试策略偏差**：旧脚本不避飞弹，遇到机缘总会追逐，不能代表每一道统的熟练玩法。新增对照策略识别飞弹、沿法域走位、更谨慎争机缘，并优先补养息。它同时改变多项决策，不作为单变量因果试验。
2. **法力不是这批样本的瓶颈**：四道统基线中神通缺法等待均为 0 秒。不能据此推论所有玩家、箓气和选卡都不会缺法。
3. **持续小伤与输出方式差异**：基线中离火、兑金平均每分钟实际失血约 52.4、49.8；明阳约 32.2。明阳甲兵能在角色避险时继续追击，并有消弹、返伤等能力。离火心火依赖近身，两个命法也不能直接替代防御。这是机制差异与策略共同作用，不是单独发现了一个“胜率开关”。
4. **可复现实现问题**：大离书原启动阈值 165、实际三重范围 115，存在范围外提前启动。回归在原版失败，在本版通过。
5. **离火仍是主要剩余问题**：大离书起手在本轮策略下仍未通关；只改起手为顺平征的十局对照中，青尺剑、种子 42 在 751 秒通关，其余九局死亡。证明存在该输入路线，不证明整体平衡。

合并改进策略的三个种子：总通关 23/60→32/60。这不是玩家胜率、真人验收或统计显著性结论，也不能把差异完全归于某一个改动。相同种子在击杀、走位变化后会消费不同的随机序列。

首轮尝试扩大心火、延长心火及秋域持续时间，没有稳定改善，已撤回，未进入本版。基线、撤回试验、最终对照、预留种子、起手对照和失败回归均保留在 `0.31.0-evaluation.json`。
