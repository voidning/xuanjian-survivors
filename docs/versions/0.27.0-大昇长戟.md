## 玩法

大昇是第五件可选器物：普攻前方200范围、150度横扫，34伤害、0.85秒间隔，不耗法力。习戟每阶扩大20度，最多190度；摄物仍增加普攻距离。洞泉声助击每次横扫消耗一份，覆盖扫中的敌人，帝观元标记每次普攻最多触发一次。

G耗24法力、冷却7秒，240范围横扫62伤害。明阳成就第一道神通后，局内视作完成炼器，追加265范围20伤害戟影；同时放出1—5道揽照白光，数量取已成就的明阳神通数。白光随武器方向运动，命中一敌造成24伤害后消失；未命中最多保留4秒。渌水神通不计数，不开启明阳神妙。数值、范围、时限、自动炼器为游戏简化，不添加无敌、斩杀和人物黑焰戟术。

原文依据：季越人《玄鉴仙族》《喜事》（第952章）明确描述原法器明光附身、照人以及后来的效附、揽照；白光未中不消、随兵器舞动，数量与明阳神通有关。并非开局就具有灵胚全部效果。效附只取分光抵敌，用额外戟影攻击表现，不实现泛化免伤；原法器完整的明光照人心绪作用未实现。
