# 0.18.0 · 神通评级与稀有参悟

日期：2026-09-08。基于 0.17.0；保留既有果位效果和五道齐备、其中一法三重的成型门槛。

## 玩家可见的变化

- 候选卡、战场已学神通栏、神通谱和诸法运转直接显示 S／A／B 字母徽记；主修和手动施法选择也显示评级。神通谱修习进度使用「重」，与评级区分。修行强化、箓气不套用神通评级。
- 高评级新法更少见：未学神通基础相对权重 S=0.35、A=0.70、B=1。权重不是出现百分比，也不代表当前搭配必选。S 的发现机会降低最多；A 相对 B 降权，但因 S 腾出候选位置，A 的总占比可能上升。
- 已学神通升重统一权重 1.25，不受评级降权；已有同参路线的未学神通仍获 1.45 倍扶持。普通参悟保留两神通一修行强化（有效神通足够时）；事件、重抽使用同样权重。
- 果位补缺与精修保底保持原规则：已启动路线连续三次候选没有目标，下次优先预留一个目标位置；多路线仍按既有优先级竞争一个保底位置，不承诺每条路线都四次必出。五道齐备后目标转为未满三重的同参。保底中的具体目标仍加权选择；最后仅缺一项时必给该项。候选已给而主动选生存强化、或自行重抽，会延后成型。
- 开局仍从原有器物适配分组中选三组，按组内平均权重选组，再按神通权重选法。屏风开局仍只给可输出神通，不增加空转开局。没有新增幸运属性、局外数值成长、付费刷新或求金门槛。
- 项目 AGENTS.md 新增长期规则：每版新增更新说明，记录变化、影响、实际验证及待验证事项，并随发行版交付、保留历史说明。

S／A／B 评级、概率、同参扶持、果位解锁门槛均为游戏规则，不是《玄鉴仙族》的原著品阶。本轮没有新增原著能力或更改已核实的核心神通作用；此前果位原文依据和边界仍见 0.17.0 更新说明与设定对照。

- 相关逻辑／构造回归：rarity 5/5、training 12/12、fruit 10/10、experience 10/10、refinement 8/8、playability 15/15、encounters 18/18，共 78/78。覆盖首次发现权重、已学升重、S 级最后缺项保底、两神通一强化、开局适配和全部神通徽记。
- 每场景一万种子、无已学神通的受控抽样：普通参悟 S 占神通位置由 7290/20000（36.45%）降为 4095/20000（20.48%）；事件由 36.74% 降为 21.08%；开局由 39.82% 降为 24.80%。这是特定状态下的候选位置占比，不是整局见到 S 的概率。定向事件、已学升重、保底与候选池缩减都会改变实际分布。
