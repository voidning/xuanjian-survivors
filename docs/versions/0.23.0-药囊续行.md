# 0.23.0 · 药囊续行

增加所有构筑都能争取的受伤恢复机会：击杀普通敌人，清出通道，再走过去拾取药囊。没有新增按键、回血神通或果位门槛，原有强化、神通和精英／首领回血数值不变。

## 药囊规则

- 每份回复 15 气血，以实际缺血量为限；赭色小药囊与青色经验珠区分，靠近 28 距离自动拾取。
- 满血不消耗，药囊不吸附、不自动过期；地上最多保留三份，满额不替换已有药囊。
- 开局及两次掉落间至少间隔 45 秒。间隔结束后，每次符合条件的普通击杀有 4% 掉落机会。
- 距上次掉落累计 40 次普通击杀后，满足间隔的后续击杀保底。气血不高于上限 35% 时，击杀要求降为 8 次。间隔内的击杀也累计；保底不会越过 45 秒间隔与三份容量。
- 精英、首领、敌方召物不触发药囊掉落。精英／首领原有直接回复 10／24 气血保留。
- 采用独立随机流，不直接消耗候选、刷怪或战斗随机序列。实际走位与存活改变后，后续战局和候选仍可能随之变化。
- 暂停、参悟、死亡不拾取；同帧致死不能靠地上的药囊复活。

## 反馈与复盘

药囊落地和拾取都有简短提示，拾取显示实际回复量。低血且附近有药囊时提示清出通道取回。结算与修行录记录掉落、拾取、真实恢复量和剩余份数；重开清空场上补给，旧存档仍能读取。

药囊为本作战场补给，不是新增原著神通、器物或丹药设定，不声称具有原著出处。既有能力和考据不变，本轮不增加原著阅读链接。

## 验证与限制

- 新增药囊逻辑／构造测试 8/8，加上既有核心循环、主修、训练、果位、蓄能、候选、瞬移、事件与呈现回归，合计 106 项通过；JavaScript 语法检查通过。
- 独立只读验收通过：额外比较与 0.22 相同种子的 200 次普通击杀，经验与下一次战斗随机值一致；关闭随机掉落后验证 40／8 次保底边界；核对出生保护、精英、首领和召物排除、同帧死亡不复活、包装链、真实小数恢复量存档。
- 输入驱动对照：0.22 与 0.23 各 48 局，剑／弓／屏、两条果位、两种选择策略、两个种子、长鲸／行气吞灵；新版策略在气血低于65%时争取最近药囊，并沿用危险回避。没有注入气血、经验、等级、技能或时间，保留自然死亡，上限800秒。
- 这组模拟通关 22→37，成型 39→45，均无超时。新版累计拾取390份，实际恢复约5467气血；长鲸组通关13→19，行气吞灵9→18。说明该策略下恢复压力显著降低，也提示可能偏宽松；不是面向所有玩家的胜率结论。
- 浏览器及离线包检查通过：主页图片、正常入口、瞬移、药囊规则加载、指南、键盘拾取、回血提示、结算与存档；页面错误为零，发行包测试注入入口已剔除。结果随验证记录交付。浏览器的受伤和连续击杀为构造场景，随后用真实键盘完成选卡、走位拾取和界面操作；不等同于真人完整十二分钟体验。

本版为15点药囊试行值。尚未进行真人整局平衡验收，优先观察“受伤后能否救回来”以及“药囊是否削弱养息、固本等选择”。本轮不叠加提高其他恢复数值。

测试入口：`node tests/medicine.cjs`；`node tests/medicine-flow.cjs`。后者可设置 `XJ_GAME_ROOT` 对照另一版本。
