# 0.19.0 · 六合敕令与战场清晰度

2026-09-08，基于 0.18.0。

- 修复战场评级：浅色大徽记改为透明底、高对比度 S／A／B 小标记；一至三重另列。修复原因是旧 `.chip span` 的浅字色覆盖了评级颜色，并叠加浅色徽记底。
- 明阳果位撤掉额外仙将，改为「六合敕令」：天下明在施放点于 0、0.6、1.2 秒连续三次禁闭、消弹与打击，范围为原来的 1.2 倍；每次伤害 22/30/38、禁闭 1.6/2/2.4 秒、忽略减伤。仍耗 26 法力、冷却 8 秒。后两次留在施放点，不随人物移动，不额外耗法，不清地面危险、不反弹、不无敌。保留谒天门普通甲兵和其余既有同参联动。
- 取消甲兵和双果位的常驻装饰光圈，果位身份改为人物上方小印记；六合用短促六向光痕及禁闭标记，保留成型瞬间提示。
- 友方法域统一绘制，去掉重复边界、圆形倒计时和持续大字：雨丝、令旗、山石、钓线、白焰分别识别神通。血漠因离域返伤与挪移保留一条真实边界，靠近边缘时加深；敌方地面危险、冲锋及飞弹预警保留。范围判定没有随视觉改成方形或扇形。
- 修复 0.17.0、0.18.0 离线包漏带首页山水图的问题，图片内嵌当前 HTML。新增 `scripts/build-release.py` 固化打包，缺图时失败，同时要求本版更新说明；无需另拷图片目录。旧发行包保留。
- 成型门槛、神通评级权重、两神通一强化与果位保底不变。

## 原著依据与游戏改编

重新核对《六合》章节中天下明的作用段落：六合之光用于敕令禁闭、消解恶难。沿用本作禁闭与消弹映射；三次节拍、数值、果位解锁和表现方式均为游戏改编，不声称原著果位自动获得三次攻击。没有把法域减噪当成新原著能力。
