- 首领条显示当前招式和收势机会。危险轮廓置于特效上方，修正旧首领冲锋标线误叠到新首领的问题。
- 修行录保存遇见、第二阶段及击退，包含人物背景、应对和章节定位；支持与旧纪录合并。无效击退时间不会被导入成已击退。

## 原著与改编边界

原作：季越人《玄鉴仙族》。已核对《都仙事》《一符一箓》《飞举山落》正文，分别支持敌对时期背景、白山紫水配合、两神通外观及人物境界。几何、数值、半血转段、山场相逢与编队均为游戏设计。邺桧取敌对时期形象，击退不代表原著陨落；不挪用雷火灵器能力。详见 `docs/邺桧斗法依据与实现.md`。

```sh
node tests/duel.cjs
node tests/duel-journal.cjs
node tests/duel-art.cjs
XJ_POLICY=adapted XJ_ITEMS=bow XJ_SEEDS=42,907 node tests/balance-flow.cjs
XJ_POLICY=adapted XJ_ITEMS=sword,spear XJ_SEEDS=42 node tests/balance-flow.cjs

python3 scripts/build-release.py
```
