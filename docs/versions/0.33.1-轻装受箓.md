# 0.33.1 · 轻装受箓

- 修复手机竖屏触发机缘时的巨大绿色提示栏。根因是 `body.has-field-event #notice` 的旧顶部定位覆盖移动端 `top:auto`，与底部定位同时生效，导致提示框被拉伸。现在正常与机缘状态都使用底部定位、内容高度和两行上限；同时修复机缘首领条的旧定位覆盖。
- 恢复 0.32 的完整卡片样式与“受此箓”按钮，取消本轮受箓的分类分页、短卡和独立确认流程；数字键直接选择可见卡片。
- 当前总共保留六种：重海长鲸、竭命功成、长空危雀、彩彻云衢、明霜松岭、贪罟玄离。贪罟玄离仍要求离火大离书三重，因此一般受箓时显示五种，符合条件后显示六种。可暂缓受箓。
- 行气吞灵、明彰日月、力贯千钧、避死延生退出新局候选；谷风引火继续关闭。保留历史 ID、说明和旧修行记录，不清空存档。
- 新地图工作暂停，未混入本次修复。
