# 《玄鉴仙族》游戏玩法规则

## 核心目标

制作供自己玩的最简类幸存者游戏。以《玄鉴仙族》的神通、箓气、器物和果位构成搭配玩法。先验证好玩，再扩充内容。

以无限生存为主模式，不设三分钟强制结束。单地图、单角色起步，移动避敌、聚怪，自动普通攻击，击杀拾取经验，通过随机选择神通形成搭配。死亡结束，也可暂停后主动结束并结算。支持重新开始、暂停与静音。

核心循环：躲避与聚怪 → 击杀拾取经验 → 随机三选一 → 技能组合变强 → 应对新的敌群压力 → 获得关键神通、果位质变 → 继续挑战。

设计重点是每轮成长值得期待、变强有明显反馈、不同选择形成不同打法。原著设定服务于这一循环。

## 一、经验与成长

循环：击杀敌人 → 拾取经验 → 经验条满 → 暂停战斗 → 三选一 → 恢复战斗。

经验用于获得成长选择，不直接增加伤害，不直接兑换果位，也不等同于箓气。

成长选择包括：
- 获得新神通，增加新的能力。
- 强化已有神通，提升效果，不增加重复技能实例。
- 选择果位配方中缺少的神通，推进成套。

“补配方”本质上也是获得新神通，不是额外的一种货币或技能。

## 二、神通就是技能

- 使用原著神通名称作为主名称，例如「君蹈危」「天下明」「仙无漏」。通俗描述只作为效果说明。
- 每道神通具有可辨认的独特效果，不能全部做成攻速、伤害加成。
- 允许跨道统自由选择。例如选择「天下明」后，仍可选择「仙无漏」。
- 道统标签用于分类及配方识别，不锁定技能池。
- 自由混选属于游戏化开放，不宣称原著修士可以无条件兼修全部神通。
- 暂不限制神通数量，不设六槽上限。用有限的成长机会与逐渐增长的升级需求形成取舍；神通等级首轮可暂设三级，按试玩调整。
- 重复获得同一道神通只提升等级，不增加重复技能实例，也不算两道神通。
- 首轮不做槽满替换或遗忘系统。学新神通与强化已有神通竞争同一次成长机会。
- 同一道神通的异名不能重复计数；替参是否可代替配方位置，必须按原著关系逐项核对。

## 三、五神通配方与果位

- 每个果位对应一套经原著核对的五神通配方。
- 集齐指定五道神通，各至少一级，即激活对应果位，不要求全部满级。
- 五个同道统技能不一定等于正确配方，必须匹配明确的神通清单。
- 果位独立于神通收集。
- 五道配方神通加一道异道神通可以同时使用：果位正常激活，异道神通正常生效。
- 器物和箓气赋予的类似能力，不算修成该神通，不计入配方。
- 不设置遗忘系统时，已完成配方持续有效。未来若加入移除神通机制，需要同步重新计算配方。
- 首批只实现一个果位效果。未来多个配方同时满足时的叠加或选择规则，待验证后确定，不预先限制成单果位槽。
- 果位带来独特联动或规则变化，不仅是统一提高伤害。
- 余位、闰位暂不实现，不能凭混搭数量或元素组合自行推导。
- “收齐五神通即可激活果位”是游戏化简化规则，不是对原著登位条件的完整复现。

例子：
- 天下明＋仙无漏：允许混选，仙无漏不计入明阳配方。
- 指定五道明阳配方神通＋仙无漏：允许，激活对应果位，保留仙无漏效果。
- 三道明阳＋三道其他神通：允许；未满足完整配方时，不获得果位，依靠技能互补形成打法。

## 四、箓气与法力

- 普通攻击不耗法力，部分强神通消耗法力，法力自动恢复。
- 法力不足仍能移动和普通攻击，不让玩家只能原地等待。
- 箓气对应本局特性，改变资源循环、爆发、恢复或行动方式。
- 暂定一局受箓一次、选择一种，独立于神通收集，不计入果位配方，本局不更换。
- 受箓通过独立事件获得，安排在前期精英或独立事件奖励中，具体时间按无限模式试玩调整；选择时暂停战斗。
- 特殊受箓的资格、候选效果需要核对原著，不直接把所有箓气当成无条件通用技能。

候选方向，具体加入前核对：
- 重海长鲸：增强法力容量与恢复，支持持续施法，不是自动回血。
- 竭命功成：消耗寿元换取法力与爆发。如果用有限的本局寿元额度表现，应注明为游戏化抽象，代价不能被普通治疗恢复。
- 长空危雀：腾挪、交战强化，具体触发条件属于游戏设计。
- 谷风引火：火法操控、真元法力精炼。

首批只需两种有明显差异的箓气。

## 五、器物

- 暂定一个器物位置，开局从两件中选择一件，本局不更换。
- 独立于神通收集，不计入果位配方。
- 提供攻击方式或战术手段，与神通、箓气产生搭配。
- 每件器物需要有清楚的独特功能、消耗、使用条件与限制。
- 先核对具体器物的原著描写，再决定效果，不依据名称猜测。
- 法器、灵器、仙器不直接串成通用颜色品质或合成升级树。
- 仙器按具体器物单独设计，首批不要求加入。
- 不做背包、随机装备词条和大量装备槽。

## 六、随机选择与成型节奏

- 每次升级从三个不同的有效选项中选择一个，选择时暂停战斗。
- 选项随机包含新神通或已有神通强化，不保证每次各占一项。
- 已获得道统的相关神通可以有轻度权重倾向，但其他道统始终有机会出现。
- 不每次保底提供配方缺项，不自动补第五道，不按固定步骤领取整套神通。
- 配方可查看已得与缺失项，但查看或标记目标不等于保证缺项出现。
- 击败精英可以获得少量、可积攒的重抽机会；重抽更新本次候选，不保证抽中目标。
- 偶尔出现指定道统的选择事件，缩小候选范围，但仍保留随机性。
- 同一次三个选项不重复，不出现已满级的无效升级。
- 收集新神通、强化已有能力、保留资源寻找关键技能之间应有取舍。
- 不设两分钟凑齐或固定每局十至十二次选择的目标；果位是值得期待的阶段质变，不保证每局都拿到。
- 未集齐果位时，单神通和混搭仍须足够有效，不能因为缺少第五道就打不动。
- 混搭不额外扣属性，代价主要是成长机会；果位强在协同，散搭强在灵活互补。
- 无限模式下需观察“无限时间＋无数量上限”是否导致后期所有搭配趋同。先通过升级节奏、敌人压力和强化取舍验证，不直接重新引入硬槽位限制。
- 有效神通选项耗尽时，应提供明确有效的续航或有限属性成长选择，避免空选项、死循环和无限重抽；具体补充奖励数值按试玩确定。

## 七、无限模式、敌人与波次

### 结束与记录

- 不因到达固定时间或击败首个首领而强制结束。
- 死亡或玩家主动结束后结算：存活时间、击杀数、击败精英及首领数、所得神通与果位。
- 重开清空本局状态，记录不作为永久属性加成。

### 压力节奏

- 前期：认识技能、收集基础能力、开始选择方向。
- 中期：精英、远程和区域危险共同出现，检验搭配。
- 后期：果位成型后仍有更复杂的敌群组合与首领可挑战。
- 交替安排高压波与短暂缓冲，让玩家有机会拾取经验、观察变化。
- 难度随时间增长，但不能只无限增加血量与数量。优先通过敌种比例、出场位置、行为组合和精英机制变化提高挑战。
- 有清楚的爆发预警和可躲避空间，避免依靠不可读的突然伤害制造难度。
- 无限模式需有实体数量控制、对象回收与掉落合并等措施，避免长时间运行后卡顿；性能上限不应导致玩法停止增长。

### 首批敌人行为候选

| 类型 | 行为 | 玩家应对 |
|---|---|---|
| 围攻者 | 成群追近、逐步包围 | 聚怪、控制、突破包围 |
| 冲锋者 | 明确直线预警后突进 | 横向闪避、避免直退 |
| 远射者 | 保持距离，发射可躲避弹道 | 接近、控制、调整路线 |
| 布阵者 | 制造暂时性的地面危险区 | 观察地面、规划路线 |
| 护持者 | 为附近敌人提供保护 | 优先击杀或使用压制手段 |
| 重甲者 | 移动慢、攻击前摇长、打击重 | 抓空隙输出，避免硬吃 |

- 敌人要有可辨认的剪影、体型、持物或动作差异，不只是同一敌人换颜色与血量。
- 表中是游戏行为原型；具体映射原著修士、妖物或器物前另行核对，不把自创行为说成原著事实。
- 加入一个阶段首领，组合已教会玩家的机制；击败后发放奖励并继续生存。

## 八、制作范围与顺序

先做完整循环，再分批补充内容。建议首个可验证内容集：
- 一套核实完整的五神通果位配方。
- 至少两道可混选的其他神通，共七道起步；后续按随机分布与搭配效果扩充。
- 一个果位特殊效果。
- 两种箓气。
- 两件功能不同的器物供开局选择。
- 敌人逐步达到六种行为类型，加一个阶段首领；先验证基础追击、冲锋、远射，再补其余类型。
- 单地图、单角色、无限生存，不以增加地图和角色代替核心玩法打磨。

每加入一批能力或敌人，检查是否产生新的操作和取舍。七道技能只是首批规模，不是整个游戏的永久上限，也不足以证明大型技能池的随机体验。

不做家族经营、多代传承、复杂剧情、永久属性成长和完整果位政治体系。

技术：Phaser 3，浏览器本地运行，无账号、联网、部署或复杂构建流程。键盘移动、自动普通攻击、随机三选一升级、暂停、结算、重开。音效可用 Web Audio，用户点击开始后启用，并提供静音。

## 九、原著依据与改编边界

- 技能名称、道统归属、异名、替参关系与五神通配方，需要以原著章节逐项核对。
- 技能具体数值、获取节奏、跨道统自由搭配与自动激活果位，属于游戏规则。
- 原著神通的独特性质应尽量保留；不确定的效果不伪装成原著事实。
- 不用未经核实的百科或读者推测作为确定设定。

核对入口：
- 天下明：《六合》 
- 仙无漏的戊土归属：《离火道途》 
- 神通与尊位感应：《求藏》 
- 君蹈危：《位别》 
- 长明阶：《平定》 
- 重海长鲸与竭命功成：《收获镜面》 
- 受箓资格：《避死延生》

部分链接为章节转载，应以章节名定位并继续核对；尚未确定完整的五神通配方名单。

## 十、验收

核心体验：
1. 混选技能确实有用，能够改变走位与出手时机。
2. 神通获取有随机性，第五道出现有惊喜；玩家也能通过重抽与事件主动争取，未凑齐时仍能战斗。
3. 果位激活明显改变打法。
4. 选择不同箓气或器物后，同一套神通需要不同的资源管理或战术。
5. 敌人行为与组合要求玩家调整走位、目标和技能运用。
6. 不同局产生不同搭配；每轮升级能让玩家想继续战斗。
7. 成型后仍有压力与新目标，无限模式不是单纯拉长时间。

功能检查：移动、攻击、伤害、拾取经验、随机三选一、权重与有效选项、重抽扣除与恢复流程、果位配方判定、法力不足与恢复、受箓、有限代价、各敌种预警与行为、首领奖励后继续运行、暂停恢复、死亡与主动结束结算、重开清空、静音、长时间运行性能。

随机验证应使用多局或多随机种子观察，而不是只构造一次五神通齐全的通过场景。记录配方完成时间、未完成比例、技能选择分布及存活情况，再调整概率，不预先承诺必定成型。

区分逻辑测试、构造场景测试与正常浏览器试玩。未经完整试玩，不声称平衡或耐玩性已验证；未实际听到音效，不声称听感已验证。
