# 实际测试报告

版本：0.1 / Phaser 3.90.0。日期：2026-09-07。验收对象为本目录游戏，不包含其他历史原型。

## 交付范围

已实现：单人单图无限生存、七道三级神通、一个明确五法配方与果位联动、两种独立箓气、两件开局器物、六种敌人行为、循环阶段首领、自动普攻、经验拾取、暂停三选一、轻度道统权重、精英重抽、明阳随机事件、耗尽技能池续航奖励、静音、死亡/主动结束结算与重开。

美术：沿用参考 figure 的圆头、肢体、发髻与背剑几何，人物绘制缩放 0.80、镜头缩放 0.88；移动 180 世界单位/秒、相机指数平滑系数 7。地图 3200 × 2200，地景只作视觉提示。敌人增加持枪、弓、旗、盾、锤和冠冕长戟剪影，未引入生成图片或素材。

两份参考已逐字复制到 references；SHA-256 与桌面原件一致，原件未修改。

## 1. Node 逻辑与定向模拟场景

命令：`node tests/logic.cjs`。**27 / 27 通过**。原始输出 `tests/logic-results.json`。

这些不是完整的真人端到端试玩，而是纯模拟层断言，包括：

- 移动速度、斜向归一化、边界；零法力仍可普攻；经验必须拾取。
- 升级暂停与连续升级队列；暂停时不移动、不计时、不恢复法力；选择后恢复。
- 1,000 种子 × 每种 15 次候选：三个不同有效选项、排除满级、其他道统有出现机会。
- 同名升级不复制、三级上限、可同时持有七道；明确五法匹配、异道不妨碍果位、器物和箓气不计数。
- 重抽只在合法状态扣次；两种箓气独立；寿元耗尽不能再用，治疗不恢复寿元。
- 器物耗蓝和冷却，锐箭贯穿多敌；仙无漏净地、东羽山凝滞、蹈危抵伤、六合与甲兵响应。
- 追击接触伤害，冲锋锁线和横向规避，远射前摇与弹道，地面预警/激活，护持减伤，重甲落锤。
- 首领击败发奖后继续推进；死亡终止；重开清空本局。
- 池容量、对象复用、经验合并总量守恒；技能池耗尽后的有效续航选项。

### 发现与修正

保留 `tests/logic-initial.json` 和 `tests/logic-regression-before.json`。

| 问题 | 分类 | 处理与复测 |
|---|---|---|
| 果位测试直接把满级技能塞进候选，合法性检查拒绝选择 | 测试脚本 | 改为合法强化，果位与异道共存通过 |
| 首领测试收到经验升级后未处理暂停，误认为时间停止 | 测试脚本 | 处理奖励后的选择队列，继续运行通过 |
| 所有神通/属性满级且满血时，调息没有收益 | 实现 | 调息增加持续回血时间；回元增加持续回蓝时间；护行增加次数。添加满血回归并通过 |
| 极短真实按键可能发生在两帧之间，没有移动 | 输入实现 | 加入一帧按键缓冲；真实 D 键将 X 从 1600 移至 1603.0204，复测通过 |

内容文件初写时也发现并修正一个多余括号语法错误，之后所有游戏 JS 通过 `node --check`。

## 2. 多种子正常成长模拟

命令：`node tests/distribution.cjs 48 900`。原始逐局数据、成长选择及实体峰值见 `tests/distribution-results.json`。

方法：从零神通和正常气血开局，不注入经验、不补血、不预置配方。自动走位程序寻找经验、规避近敌/冲锋预警/地面区，并按条件使用器物与竭命。奇数种子采用随机倾向，偶数种子优先找配方并按条件重抽。**自动走位不是人工操作，不能证明手感、真人胜率或耐玩性。**

| 指标 | 结果 |
|---|---:|
| 总种子 | 48 |
| 达成果位 | 36 |
| 未达成果位 | 12（25%） |
| 成型时间范围（成功局） | 84.7–200.7 秒 |
| 成型时间中位数（成功局） | 119.3 秒 |
| 随机倾向成型 | 13 / 24 |
| 寻配方倾向成型 | 23 / 24 |
| 死亡 | 48 / 48 |
| 存活时间中位数 | 187.1 秒 |
| 两组总首领击败数 | 9 |

技能获得局数：君蹈危 48、帝观元 47、天下明 46、谒天门 44、赤断镞 43、仙无漏 27、东羽山 27。并未固定发齐五法，但小池子明显偏向明阳；寻配方策略的成型率偏高仍是后续扩池应观察的问题。

此前 24 种子基线保存在 `distribution-before.json`：成功局最早 55.2 秒成型，未成比例 12.5%。据此提高升级经验需求，没有增加槽位上限、没有保底第五道、没有改变为两分钟固定发全套。

模拟器全部死亡不等于“三分钟强制结束”：时间推进和死亡是独立条件，模拟最长局超过 4 分钟；首领发奖后继续的定向测试也单独通过。自动走位对弹道处理不充分，不能据此把死亡统计推广为真人体验。

## 4. 真实浏览器短局操作

使用 Codex 内置浏览器，HTTP 地址仅在 127.0.0.1。没有注入该正常局的神通、经验或敌人；测试查询参数仅把诊断数据镜像为只读 DOM 属性。

最终版种子 9071，青尺剑开局：

- 实际短按 D 验证移动；点击地面移动拾取经验。
- 实际 P 暂停：时间 11.98344 秒，暂停后再按 D 与空格，时间和坐标完全不变；P 恢复后继续。
- 实际空格使用器物，法力由满值下降，进入冷却，自动回蓝。
- 正常击杀 34 敌，于 38.34998 秒拾取到升级；按 1 选择赤断镞，恢复战斗，自动施法消耗法力。
- 于 49.59990 秒正常击败首个精英，进入独立受箓；选竭命功成后，尚未消费的升级继续进入三选一，没有丢失。
- 点击重抽，次数 1 → 0，三个候选实际更新；按 1 学谒天门。
- 实际 Q 消耗寿元 8 → 7，再用空格器物；并存两道神通与独立箓气。
- 59.26657 秒主动结束：60 击杀、1 精英、0 首领、果位未成；结算显示符合当局数据。
- 点击同局种重试后：零技能、无箓气、寿元 8、气血/法力 100、经验与击杀归零。

证据：`tests/browser-input.json`、`tests/正常升级.png`、`tests/正常战斗.png`。截图均直接来自运行中的浏览器。

这轮短局没有自然取得果位，也没有人工击败阶段首领；这两项的证据来自多种子模拟和构造场景，不能混为真人完成。E 挪移的域、法力与冷却条件已通过模拟测试；这轮正常局按 E 时恰逢受箓暂停，没有把该次输入算作成功挪移。长期平衡与完整手感未验收，音效没有实际听感验收。

当前独立正常测试页的错误/警告日志为空，见 `tests/browser-console.json`。早期 iframe 构造页的浏览器工具曾报告一次 MutationObserver 非 Node 参数错误；项目源码和本地 Phaser 未包含该符号，暂归类为验证环境异常，不宣称整个工具会话零错误。16 项构造断言仍通过。

## 5. 长时性能压力场景

命令：`node tests/soak.cjs`。原始数据：`tests/soak-results.json`。

**构造前提**：预置七道满级与果位，每步恢复气血以维持压力。模拟 3,599.95 秒、72,000 步，真实计算耗时约 6.34 秒；不是浏览器持续运行一小时，也不证明可自然存活一小时。

| 实体 | 观察峰值 | 容量上限 |
|---|---:|---:|
| 敌人 | 149 | 160 |
| 弹道 | 44 | 240 |
| 经验掉落 | 110 | 110 |
| 区域 | 31 | 36 |
| 甲兵 | 6 | 8 |
| 短效特效 | 78 | 120 |

最终仍在运行，击杀 10,379、精英 54、首领 19；回收远敌 519 次，掉落合并 9,482 次。经验合并守恒另有断言。单步模拟耗时中位数 0.079 ms、P95 0.145 ms、P99 0.337 ms；这些数值不包含浏览器绘制，不能换算成游戏 FPS。记录仅保留最近 512 次成长，避免历史无限增长。

未执行浏览器一小时持续渲染和跨机器帧率验证。Node 堆内存受 GC 影响，原始采样保留，不据单次样本宣称完全没有内存泄漏。
