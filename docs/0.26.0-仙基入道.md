# 0.26.0 · 仙基入道

日期：2026-09-09。

从筑基起步，开局列出明阳、渌水两道统共十道仙基，选择后锁定本系五法。移除当前果位玩法及跨系混修入口，其余旧技能保留为待开放图鉴，历史存档保留。重明洞玄屏与谷风引火暂不开放。

一、二重为仙基蕴养，三重成就神通。除有仙基层正文依据的谒天门落门镇压外，前两重不沿用对应神通战斗效果。第 1—5 道神通突破等级为 7／11／15／20／24；已成就神通数 1／3／4／5 分别显示紫府／紫府中期／大真人／五法圆满。玩家前期主要依靠器物作战，不能用低重血漠挪移、泉势助击、清雨破护或六合控场。

天下明三重仍须玩家主动指定 F 才启用蓄能六合敕令，不自动接管 F。指南、图鉴与操作说明按当前三重有效数值同步，并标出仙基与神通阶段边界。

## 原作依据与改编

作品《玄鉴仙族》，作者季越人。第729章《戟兵首威》支持谒天门仙基层显化天门与镇压，不支持仙基召兵；短暂范围控制与数值为游戏量化。其余九法仙基层对应战斗效果本轮未获得充分正文证据，保持蕴养而不下放神通。未核实不等于原著没有。重数、等级门槛与境界显示均为用户指定的游戏规则，不声称逐项还原原著修行过程。

- 独立只读验收：核心与兼容通过；发现修行录推荐关闭内容的问题，修复后复验通过。历史果位及器物勋记保留，仅过滤当前目标候选。
- 浏览器正常入口冒烟：择器、十仙基选卡、0键选择第十项、暂停、神通谱往返；390px窄屏可滚动并选择最后一张卡。无页面运行错误。
- 构造视觉检查：明阳、渌水各筑基／紫府／紫府中期／大真人／五法圆满五阶段，角色光环层次与减少动态效果模式；这些不是自然成长通关证据。
- 单文件离线冒烟：屏蔽HTTP请求后以file入口成功择器、选择清夕雨并暂停；零HTTP依赖，发行本体无测试注入入口。
- 固定输入策略模拟16局，7胜：明阳6/8、渌水1/8；自然生命、经验、候选与敌人节奏，不注入成长。首道神通83.5—94.0秒，三道296.8—342.7秒，四道472.7—519.3秒，五道633.0—647.4秒；区间只统计实际达到该阶段的局。
- 围绕雨域的渌水走位对照8局0胜，说明这一策略没有解决难度差异；不能将弱势简单归因于走位，也不据此推导真人胜率。
- 另16局在四神通后主动不升第五道，明阳6/8胜、渌水0/8胜；获胜局均为四神通。五法圆满不是胜利硬性条件，渌水四法强度尚未证明足够。

未执行真人完整通关体验，渌水明显偏难，两条路线未宣称调平。此版交付用于试玩仙基成长与境界特效；重明洞玄屏暂关闭，其他道统留待补足可靠依据后开放。

## 进阶考据边界

《大离熙光》《齐晞》区分三神通真人与四神通大真人，因此本版未沿用最初设想的三法即大真人。五法圆满与四法大真人分层，但不概括所有道统特殊修法；《嬗变》所见坎水特殊情形不纳入当前两条路线。仙基三重即神通、角色等级门槛和三法显示紫府中期是局内压缩规则，不等同原著修炼原理。
