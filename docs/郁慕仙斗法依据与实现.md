# 郁慕仙斗法：原著依据与游戏实现

版本：0.35.0 · 金销藏器。原作：季越人《玄鉴仙族》。依据为实际核对的章节正文；转载目录的编号可能不同，以章名为准。

## 原著定位

郁慕仙是与李家有阶段性冲突的元乌峰修士，取洞天交锋时期的筑基后期形象。第467章《交战（上）》写其六面圆盾协同护身，另有八枚菱形法器；金销洞仙基可在体内蕴养法器。遭近攻时他以金莲护身。六石云盘是此前练手之作，不能把实战的六盾直接命名为六石云盘。

第469章《剑斩》记李渊蛟以青尺剑内剑意斩杀郁慕仙。本作只安排一次山中斗法并记“击退”，不让玩家扮演李渊蛟，不搬用其剑意，不声称这是原著死亡事件。

## 出场与原有内容

修为达到5级、已选道统、尚无成就神通、游戏时间小于180秒且无在场首领时，生成郁慕仙一次。检查从正常战斗步推进，不依赖测试入口或手工设置时间。若对象池已满则重试，不记为已遇见。出场替代原180秒首领位，下一常规首领位不早于360秒；若未满足条件，原180秒首领保持。

这是早期成长阶段的游戏门槛，5级不是原著境界分层。战斗中升级、选卡、突破都正常进行；玩家即使先进入紫府，也不把郁慕仙提升为紫府。邺桧及其六分钟后的原准入条件保留。无尽开局同样可遇；本局每人最多一次。终阵开启时仍在场的具名对手退去，不算击退、不发奖励。

## 本版实际机制

- 气血560，六面法盾共120耐久。伤害先按已有玩家增伤、敌方抗性结算，再由耐久吸收，溢出扣气血。护盾不自动再生，破盾取消其当前出招并清除其遗留飞弹，收势2.5秒供追击。
- 八枚菱形法器：1.5秒锁定预警，从左右各四枚交叉发出；所有道统都可用正常走位离开射线。第一阶段速度185，第二阶段205，寿命2.6秒，单枚基础伤害9。形状、角度、射程、伤害与预警是游戏抽象；程序中的“金梭”只为形状简称，并非原著独立器物名。
- 半血一次转段：取消在途攻击，展开96耐久金莲，收势2秒；不锁血、不恢复气血。破莲仍可获得2.5秒追击空档。这个转段触发条件为游戏设计。
- 攻击后第一阶段收势2.3秒、第二阶段1.8秒，另有1.5秒换位。近身基础伤害11。既有打断、消弹、停顿与隐匿规则照常适用；不要求特定神通或箓气才能打赢。
- 不实现天金镲的追溯探查、翠勾动法、止戈、另一灵器、体内符箓和药物恢复。没有把法器干扰写成全技能沉默，也没有将紫府灵器解释成人物境界或仙基自带能力。

具名首领在场时沿用0.34.0减压调度：暂停新增精英，非蓄势且残敌少于28时每5秒至多补两名普通围攻者。既有精英、机缘敌人仍可能在场，不是强制单挑。

击退只发一份原首领奖励：重抽2、回复24气血、经验掉落95。两名对手分别保存遇见、转段和击退时间，修行录、导入合并及结算展示兼容此前仅有邺桧的记录；不增加永久战力。
