# 0.29.0 · 十法成长反馈

现有明阳、渌水十法一重获得局部战斗作用，二重增强；三重切换为既有完整神通。离火、兑金草稿仍隔离，未接入。保留原有存档键、境界门槛、全屏成就提示、递进光环与大昇。
