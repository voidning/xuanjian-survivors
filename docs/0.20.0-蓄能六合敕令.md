# 0.20.0 · 蓄能六合敕令（试行）

- 明阳果位现在解锁一个 F 蓄能主动技「六合敕令」。首次成果位满能，可以立即体验；此后满能按 F 或点击战场按钮释放，能量清空，不耗法力。
- 普通天下明恢复单次自动施放。原果位附带三连敕令移到主动技，不再每8秒自动发动；三次伤害、禁闭与消弹仍固定在施放点，间隔0.6秒，范围为普通天下明的1.2倍。普通神通耗法与冷却不变，其余果位联动保留。
- 战斗时间蓄能：650范围内有已入场敌人或敌弹时每秒+2.5；普通击杀+0.15、精英+4、首领+8，每轮击杀最多补12。100满能可一直保留；纯时间40秒，最大击杀补充时至少35.2秒有效战斗，脱战更久。暂停、参悟、死亡不蓄能，满能只提示一次。
- 明阳成型后 F 交给果位，原手动神通恢复自动，暂停中的手动选择停用；主修优先仍可设置。保持一个神通主动键，不增加第二排神通操作。渌水保持自动，暂不提供切换果位系统。
- 按键不接受长按连发，手机使用同一个可点击按钮。满能按钮改变颜色和文字；不额外添加常驻光圈。
- 重开清空，继续无尽保留当前能量。首次成型送能不能靠学习其他神通重复领取。

原著依据沿用《六合》的禁闭、消解恶难作用；主动槽、蓄能、三次节拍和全部数值是游戏改编，本轮未新增原著能力。门槛与稀有权重不变，首页内嵌图片和战场减噪保留。

- Chrome：构造缺最后一道同参的局面，通过真实候选点击成果位，再实际按F、再次按F、暂停查看手动选择停用、390宽页面点击主动按钮；仅首次／满能点击生效，无横向溢出，无脚本异常。测试冻结了游戏时间，因此操作后显式刷新HUD用于截图；这些是构造验收，不是自然成型。离线发行正常入口选器物、选神通通过，首页图片加载成功，未成型没有主动按钮，开发测试入口已剔除。
- 输入驱动40局均自然胜败结束，29局成果位、9局胜利；17局实际使用明阳主动，总计170次。策略只在满能且300范围内至少三敌时调用公开释放方法，不注入等级、血量、经验或能量。该自动策略不代表真人解围判断；与0.19.0已有同类样本的13/40胜利相比偏低，三连由频繁自动改为蓄能后的整体收益需要试玩校准，不能据此声称平衡改善。
