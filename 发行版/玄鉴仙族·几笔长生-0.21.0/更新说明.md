# 0.21.0 · 通用瞬移

- 全器物开局自带空格瞬移：140距离、6秒独立冷却，不耗法力、不加无敌、不造成伤害。优先当前移动方向，点击走位时朝目标，无输入时沿最后移动方向（初始向右）。手机点击「空格 · 瞬移」按钮即可。
- 瞬移取消旧点击目标，避免落地自动折返。地图边缘截短距离，贴边无法位移时不消耗冷却。停步也能使用，不依赖神通、果位或敌方目标。
- 空格不再施放器物技；器物技改为 G，自动施放、R切换和原按钮保留。同步器物卡、提示和离线手册。F蓄能果位、E赤断镞挪移、Q竭命不变。
- 通用瞬移不触发赤断镞的召兵／伤害／短暂无敌联动，E挪移仍使用独立耗法和冷却。新功能为类幸存者操作规则，不是新增原著神通或器物能力，不计入同参。
- 冷却在暂停、参悟与结束时冻结，重开清空。长按空格不自动连跳；只认新按下。首页内嵌图片、明阳蓄能和战场减噪保留。

- 主 Agent 针对性自检，未另行独立验收。相关58项通过：dash 5/5、fruit-active 6/6、experience 10/10、playability 15/15、training 12/12、fruit 10/10。
- 覆盖五器物开局可用、斜向距离归一、无耗法/无额外无敌/无伤害、六秒冷却与重复拒绝、暂停/选择/结束冻结、地图边界、死亡及非法方向输入、与血漠E独立、重开清空。六秒累计减法产生约1.3e-14残余冷却的失败已复现并修复，仅对瞬移冷却近零值归零，同一回归通过。
