# 玄鉴仙族 · 几笔长生

基于《玄鉴仙族》设定制作的非官方同人 **类幸存者游戏**。在青白山场中走位避险、自动清怪、收取经验，由仙基入道、逐步成就同道五法，迎战最后的执阵首领。

**当前版本：0.31.0 · 入山有方** · 本地 H5 · 支持离线游玩

## 开始游玩

### 从源码启动

macOS 可双击根目录的 `启动游戏.command`，脚本使用 **Python 3** 启动本地服务并打开浏览器。关闭该终端窗口即可停止服务。

也可以在项目根目录运行：

```sh
python3 -m http.server 18743 --bind 127.0.0.1
```

然后访问 <http://127.0.0.1:18743/>。游戏使用本地运行库，不需要先执行 `npm install`；Node.js 仅在运行开发测试时需要。

## 核心玩法

**走位聚怪与避险 → 自动清怪 → 靠近收取经验 → 升级补短板 → 挑战更强敌群与机缘。**

- **五件器物**：青尺剑、青乌弓、杜若枪、六雷玄罚令、大昇长戟。大昇普通横扫，明阳首道神通后器物技附加戟影和揽照白光；渌水仅保留法器重扫。重明洞玄屏从当前入口与图鉴移除，旧记录保留。
- **二十道开放仙基与八类修行强化**：开局切换明阳、渌水、离火、兑金道统页，每页展示五道仙基，任选其一定道统；后续至多三项成长候选，限同道五法。其余未开放技能仅保留图鉴，标明未开放。
- **主修与法力取舍**：普通攻击不耗法力，自动神通和器物技共用法力。首道承担伤害的自动神通默认成为主修，可在参悟或暂停界面更换，也可选均衡调度。主修与紧急防御优先蓄法，其他缺法神通先短暂让行，再轮候施放。
- **仙基入道**：开局筑基，前两重蕴养仙基，普通器物维持杀敌成长；第三重合并神通初成与精修，为本作节奏改编。下一道神通依次需要修为 7、11、15、20、24 级，不设时间门槛。首道成就入紫府，三道至紫府中期，四道至大真人，五道圆满。
- **箓气与可选机缘**：首次击败精英或首领后，每局受箓择一，获得对应人物纹饰；宝藏、守点、追猎和试阵让玩家决定是否离开安全路线争取成长。

S／A／B 是本作神通强度评级。仙基前两重不提前获得完整神通效果，具体阶段行为以游戏内说明为准。

### 一局如何结束

标准挑战在 **11 分 15 秒开启终阵**，击败终阵首领才算获胜。“约十二分钟”是体验目标，不是到点自动结算；普通首领被击败后战斗仍会继续。

胜利后可保留本局修为继续无尽，也可重开尝试其他搭配。喘息阶段适合回收经验，但残敌、精英和首领仍会行动。

## 操作

以移动和自动攻击为基础，其他能力按需使用。

| 操作 | 按键／方式 |
| --- | --- |
| 移动 | WASD、方向键，或点击地面 |
| 通用瞬移 | **空格**／战场按钮；沿移动方向位移，冷却 6 秒，不耗法力、不额外提供无敌 |
| 升级选择 | 开局每道统五张卡，按 1—5 选择当前页仙基；后续 1／2／3；受箓 1—6 |
| 暂停／继续 | P／Esc |
| 神通谱 | Tab；查阅时暂停 |
| 开关音效 | M |
| 器物技 | 默认自动；G 手动使用，R 切换自动／手动 |
| 指定一道手动神通 | F；仅成就神通后可在暂停界面选择，随时可改回全部自动。天下明成就神通后且选为手动时使用蓄能三次敕令 |
| 血漠挪移 | E；需赤断镞成就神通、身在自己的血漠内，并满足法力与冷却条件 |
| 竭命功成 | Q；需对应箓气，每次消耗不可恢复的寿元 |

天下明成就神通后选为 F 才使用蓄能三次敕令，升重不会接管 F；清夕雨成就后强化定点雨势与离雨破护延续，洞泉声成就后共六次助击。详细数值与限制见游戏内「设定与效果说明」。

## 结算与记录

结算回顾境界与五法修行、受伤来源、主修、机缘与缺法等待。旧版果位记录只作为历史保留，不影响新局。

修行录保存在当前浏览器本地，可导出备份、合并导入；不保存战斗中途进度。不同浏览器或打开地址的记录未必共用，换入口前建议先导出。源码游玩时可固定使用上述本地地址。

## 开发与验证

在根目录使用 Node.js 运行相关检查：

```sh
node tests/cultivation.cjs
node tests/dasheng.cjs
node tests/dash.cjs
node tests/medicine.cjs
```

输入驱动模拟入口：

```sh
node tests/cultivation-flow.cjs
node tests/dasheng-flow.cjs
XJ_RAIN_AWARE=1 node tests/cultivation-flow.cjs
node tests/dasheng-flow.cjs
```

脚本按固定策略移动、选卡与使用瞬移，保留自然成长和死亡；第二项是渌水雨域走位对照。它们不是浏览器交互测试，也不能代替真人试玩。旧测试保留历史版本契约，含果位、混修、三槽等断言，不能作为 0.26 现行规则的验收命令。

本原型的测试与验收结果以本次实际执行记录为准；旧版本检查不能证明当前版本通过。构造场景或模拟通关不能代替真人体验验收。
